# NLP Coach Oefenapp

Oefenapp voor de opleiding NLP Coach met Impact. Eén HTML-bestand, geen server nodig. Werkt ook offline zodra de pagina eenmaal geladen is (alleen het lettertype komt van Google Fonts).

## Op GitHub Pages zetten

1. Maak een nieuwe repository aan en upload `index.html`.
2. Ga naar **Settings → Pages**, kies bij *Source* de branch `main` en map `/ (root)`, en klik **Save**.
3. Na een minuut staat de app op `https://<gebruikersnaam>.github.io/<repository>/`.
4. Open die link op je telefoon en kies **Zet op beginscherm**.

Voortgang wordt per browser bewaard (localStorage); iedereen houdt zijn eigen voortgang bij.

Inhoud gebaseerd op de readers van De eerste verdieping opleidingen (NLP Coach met Impact en NLP Master Practitioner). Items met het label "aanvulling" komen uit openbare online bronnen.
